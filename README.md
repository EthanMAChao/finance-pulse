# Finance Pulse Model V2

这是高置信动态股票/基金决策模型版本。

## 重要原则

本模型不能保证未来胜率达到90%。  
V2采用的是“目标胜率门槛”：只有当历史滚动回测信号胜率达到目标值，且当前趋势、动量、风险同时达标时，才输出“高置信机会”。

## V2优化

- 新增目标胜率门槛：默认90%。
- 新增滚动回测模块。
- 新增信号次数、命中次数、历史胜率、未来平均收益显示。
- 更严格的高置信信号筛选。
- 达不到目标胜率时，自动降级为“等待回踩确认”或“回避观察”。
- 修复底部导航、缓存、动态数据、安装反馈等体验问题。
